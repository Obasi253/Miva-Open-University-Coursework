# COS 106 - Lab 2 Theory Answers (Exercise 2.1)

## 1. Table Tag (`<table>`)
The `<table>` tag is used to create a table in an HTML document[span_0](start_span)[span_0](end_span). The table row (`<tr>`) tag is used to create the rows, and the table data (`<td>`) tag is used to enter data inside the table cells[span_1](start_span)[span_1](end_span).

## 2. Style Tag (`<style>`)
The style (`<style>`) tag is used to add styling methods to the content by typing the code directly within the HTML file itself[span_2](start_span)[span_2](end_span).

## 3. List Tag (`<ul>` / `<ol>`)
The `<li>` tag is used to enter contents in a listed order[span_3](start_span)[span_3](end_span). There are two main types of lists: ordered lists (`<ol>`) and unordered lists (`<ul>`)[span_4](start_span)[span_4](end_span).

## 4. Image Tag (`<img>`)
The `<img>` tag is used to embed an image in an HTML document[span_5](start_span)[span_5](end_span). You need to specify the source of the image (`src`) inside the tag, and a `<center>` tag can be used to center the content[span_6](start_span)[span_6](end_span).
